## Prerequisites

### System Requirements

**Operating Systems:**
- Ubuntu 20.04+ / Debian 11+
- RHEL/Rocky Linux 9+
- Fedora 35+

**Required Packages:**

**Ubuntu/Debian:**
```bash
sudo apt-get update
sudo apt-get install -y \
    build-essential \
    autoconf \
    automake \
    libtool \
    pkg-config \
    libpipewire-0.3-dev \
    libspa-0.2-dev \
    pipewire \
    pipewire-pulse \
    ffmpeg
```

**RHEL/Rocky/Fedora:**
```bash
sudo dnf install -y \
    gcc \
    make \
    autoconf \
    automake \
    libtool \
    pkgconfig \
    pipewire-devel \
    ffmpeg
```

### Verify PipeWire is Running

```bash
# Check if PipeWire is running
systemctl --user status pipewire

# If not running, start it
systemctl --user start pipewire pipewire-pulse

# Enable on boot
systemctl --user enable pipewire pipewire-pulse
```

## Building from Source

### 1. Clone Your Fork

```bash
# Clone your repository
git clone https://github.com/Ayushtiwari27/pipewire-module-xrdp.git
cd pipewire-module-xrdp

# Checkout the FIFO implementation branch
git checkout fifo-audio-routing
```

### 2. Build the Module

```bash
# Generate configure script
./bootstrap

# Create build directory
mkdir -p build
cd build

# Configure
../configure

# Build
make

# Verify build succeeded
ls -lh src/.libs/libpipewire-module-xrdp.so
```

**Expected Output:**
```
-rwxr-xr-x 1 user user 50K Dec  3 12:00 libpipewire-module-xrdp.so
```

### 3. Optional: Install System-Wide

```bash
# Install (requires root)
sudo make install

# Verify installation
find /usr -name "libpipewire-module-xrdp.so" 2>/dev/null
```

**Typical install locations:**
- `/usr/local/lib/pipewire-0.3/`
- `/usr/lib/x86_64-linux-gnu/pipewire-0.3/`
- `/usr/lib64/pipewire-0.3/`

```bash
# Create user module directory
mkdir -p ~/.local/lib/pipewire-0.3

cp build/src/.libs/libpipewire-module-xrdp.so ~/.local/lib/pipewire-0.3/

ls -lh ~/.local/lib/pipewire-0.3/libpipewire-module-xrdp.so
```

```bash
cd build
sudo make install

# Update library cache
sudo ldconfig
```

No installation needed - can load directly from build directory.

## Configuration

### Environment Variables

Create a configuration file for easy setup:

```bash
# Create config file
cat > ~/.config/xrdp-audio.conf <<'EOF'
# XRDP Audio FIFO Configuration
export XRDP_AUDIO_SPK_FIFO="${XDG_RUNTIME_DIR:-/run/user/$(id -u)}/xrdp_spk.pcm"
export XRDP_AUDIO_MIC_FIFO="${XDG_RUNTIME_DIR:-/run/user/$(id -u)}/xrdp_mic.pcm"
export XRDP_AUDIO_FORMAT_FILE="${XDG_RUNTIME_DIR:-/run/user/$(id -u)}/xrdp_audio_format.txt"
EOF

# Source it
source ~/.config/xrdp-audio.conf
```

Add to your shell profile for persistence:

```bash
# Add to ~/.bashrc or ~/.zshrc
echo 'source ~/.config/xrdp-audio.conf' >> ~/.bashrc
```

## Testing

### Test 1: Load Module

**IMPORTANT:** The module requires `sink.stream.props` and `source.stream.props` arguments to initialize both speaker and microphone streams.

```bash
# Load the module (from build directory)
pw-cli load-module /home/dev/pipewire-module-xrdp/build/src/.libs/libpipewire-module-xrdp '{ sink.stream.props={} source.stream.props={} }'

# OR if installed system-wide
pw-cli load-module libpipewire-module-xrdp '{ sink.stream.props={} source.stream.props={} }'

# Verify module is loaded
pw-cli ls Module | grep -i xrdp
```

**Expected Output:**
```
module.name = "libpipewire-module-xrdp"
```

**Note:** Loading without arguments will fail with "Invalid argument" error. At minimum, you must specify either `sink.stream.props={}` or `source.stream.props={}` or both.

### Test 2: Verify FIFOs Created

```bash
# Check FIFO files
ls -lah /run/user/$(id -u)/xrdp_*.pcm

# Should show named pipes (p)
```

**Expected Output:**
```
prw-r--r-- 1 user user 0 Dec  3 12:00 xrdp_mic.pcm
prw-r--r-- 1 user user 0 Dec  3 12:00 xrdp_spk.pcm
```

### Test 3: Verify PipeWire Devices

```bash
# List sinks (speakers)
pw-cli ls Node | grep -A5 xrdp-sink

# List sources (microphones)
pw-cli ls Node | grep -A5 xrdp-source

# Or use pactl
pactl list sinks | grep -i xrdp
pactl list sources | grep -i xrdp
```

### Test 4: Check Format File

```bash
# View format specification
cat /run/user/$(id -u)/xrdp_audio_format.txt
```

**Expected Output:**
```
# XRDP Audio Format Specification
# Auto-generated by pipewire-module-xrdp
speaker_rate=48000
speaker_channels=2
speaker_format=s16le
mic_rate=48000
mic_channels=1
mic_format=s16le
timestamp=1733251234
```

### Test 5: Start FFmpeg Manager

```bash
# Make script executable (if not already)
chmod +x scripts/ffmpeg_manager.sh

# Start in background
./scripts/ffmpeg_manager.sh start &

# Check status
./scripts/ffmpeg_manager.sh status
```

**Expected Output:**
```
XRDP Audio FIFO Manager Status
===============================

Configuration:
  Speaker FIFO: /run/user/1000/xrdp_spk.pcm
  Mic FIFO: /run/user/1000/xrdp_mic.pcm
  Format File: /run/user/1000/xrdp_audio_format.txt

Current Format:
speaker_rate=48000
...

Processes:
  Speaker encoder: RUNNING (PID: 12345)
  Mic decoder: RUNNING (PID: 12346)
```

### Test 6: Play Audio to Speaker

```bash
# Play a test sound
paplay -d xrdp-sink /usr/share/sounds/alsa/Front_Center.wav

# OR
speaker-test -D xrdp-sink -c 2 -t wav

# Check if data is flowing
ls -lh /run/user/$(id -u)/xrdp_spk.pcm

# Monitor speaker encoder log
tail -f /run/user/$(id -u)/xrdp_ffmpeg_speaker.log
```

### Test 7: Record from Microphone

```bash
# Record for 5 seconds
timeout 5 parecord -d xrdp-source test_recording.wav

# Play it back
paplay test_recording.wav

# Check mic decoder log
tail -f /run/user/$(id -u)/xrdp_ffmpeg_mic.log
```

### Test 8: Loopback Test

```bash
# Terminal 1: Create loopback (speaker -> mic)
ffmpeg -f s16le -ac 2 -ar 48000 \
       -i /run/user/$(id -u)/xrdp_spk.pcm \
       -ac 1 -ar 48000 -f s16le \
       /run/user/$(id -u)/xrdp_mic.pcm

# Terminal 2: Play audio
paplay -d xrdp-sink /usr/share/sounds/alsa/Front_Center.wav

# Terminal 3: Record and verify
parecord -d xrdp-source loopback_test.wav
paplay loopback_test.wav  # Should hear the original sound
```

## Deployment Scenarios

### Scenario 1: Development/Testing Environment

**Use Case:** Testing on local machine

```bash
# Don't install, just load from build directory
cd /home/dev/pipewire-module-xrdp/build
pw-cli load-module $(pwd)/src/.libs/libpipewire-module-xrdp '{ sink.stream.props={} source.stream.props={} }'

# Start FFmpeg manager manually
../scripts/ffmpeg_manager.sh start
```

### Scenario 2: Single User Deployment

**Use Case:** One user needs FIFO audio routing

```bash
# Install to user directory
mkdir -p ~/.local/lib/pipewire-0.3
cp build/src/.libs/libpipewire-module-xrdp.so ~/.local/lib/pipewire-0.3/

# Create autoload configuration
mkdir -p ~/.config/pipewire/pipewire.conf.d
cat > ~/.config/pipewire/pipewire.conf.d/99-xrdp.conf <<'EOF'
context.modules = [
    { name = libpipewire-module-xrdp
      args = {
        sink.stream.props = {
          node.name = "xrdp-sink"
          node.description = "XRDP Speaker"
          media.class = "Audio/Sink"
        }
        source.stream.props = {
          node.name = "xrdp-source"
          node.description = "XRDP Microphone"
          media.class = "Audio/Source"
        }
      }
    }
]
EOF

# Restart PipeWire
systemctl --user restart pipewire

# Setup FFmpeg manager as systemd service
mkdir -p ~/.config/systemd/user
cat > ~/.config/systemd/user/xrdp-audio-fifo.service <<EOF
[Unit]
Description=XRDP Audio FIFO Manager
After=pipewire.service

[Service]
Type=simple
ExecStart=/home/$(whoami)/pipewire-module-xrdp/scripts/ffmpeg_manager.sh start
Restart=on-failure
RestartSec=5

[Install]
WantedBy=default.target
EOF

# Enable and start
systemctl --user daemon-reload
systemctl --user enable xrdp-audio-fifo.service
systemctl --user start xrdp-audio-fifo.service
```

### Scenario 3: Multi-User Server Deployment

**Use Case:** Multiple users on same server (VDI environment)

```bash
# Install system-wide
sudo make install
sudo ldconfig

# Create template configuration
sudo mkdir -p /etc/skel/.config/pipewire/pipewire.conf.d
sudo tee /etc/skel/.config/pipewire/pipewire.conf.d/99-xrdp.conf <<'EOF'
context.modules = [
    { name = libpipewire-module-xrdp
      args = {
        sink.stream.props = {
          node.name = "xrdp-sink"
          node.description = "XRDP Speaker"
        }
        source.stream.props = {
          node.name = "xrdp-source"
          node.description = "XRDP Microphone"
        }
      }
    }
]
EOF

# Install FFmpeg manager for all users
sudo cp scripts/ffmpeg_manager.sh /usr/local/bin/
sudo chmod +x /usr/local/bin/ffmpeg_manager.sh

# Create systemd user template
sudo mkdir -p /etc/systemd/user
sudo tee /etc/systemd/user/xrdp-audio-fifo.service <<'EOF'
[Unit]
Description=XRDP Audio FIFO Manager
After=pipewire.service

[Service]
Type=simple
ExecStart=/usr/local/bin/ffmpeg_manager.sh start
Restart=on-failure
RestartSec=5

[Install]
WantedBy=default.target
EOF

# Enable for all users by default
sudo systemctl --global enable xrdp-audio-fifo.service
```

### Scenario 4: Container/Docker Deployment

```bash
# Create Dockerfile
cat > Dockerfile <<'EOF'
FROM ubuntu:22.04

RUN apt-get update && apt-get install -y \
    pipewire \
    pipewire-pulse \
    libpipewire-0.3-dev \
    ffmpeg \
    build-essential \
    autoconf \
    automake \
    libtool \
    pkg-config

COPY . /build
WORKDIR /build

RUN ./bootstrap && \
    mkdir -p build && \
    cd build && \
    ../configure && \
    make && \
    make install && \
    ldconfig

COPY scripts/ffmpeg_manager.sh /usr/local/bin/

CMD ["pipewire"]
EOF

# Build image
docker build -t xrdp-audio-fifo .

# Run container
docker run -d \
  --name xrdp-audio \
  -v /run/user/$(id -u):/run/user/$(id -u) \
  xrdp-audio-fifo
```

### Scenario 5: Remote Desktop (XRDP) Integration

**Use Case:** Integration with XRDP for remote sessions

```bash
# Install module system-wide
sudo make install

# Create XRDP session script
sudo tee /etc/xrdp/startwm-custom.sh <<'EOF'
#!/bin/bash

# Start PipeWire
systemctl --user start pipewire pipewire-pulse

# Wait for PipeWire to be ready
sleep 2

# Load XRDP audio module with required arguments
pw-cli load-module libpipewire-module-xrdp '{ sink.stream.props={} source.stream.props={} }'

# Start FFmpeg manager
/usr/local/bin/ffmpeg_manager.sh start &

# Start desktop session
exec /etc/xrdp/startwm.sh
EOF

sudo chmod +x /etc/xrdp/startwm-custom.sh

# Configure XRDP to use custom script
sudo sed -i 's|^startwm=.*|startwm=/etc/xrdp/startwm-custom.sh|' /etc/xrdp/sesman.ini

# Restart XRDP
sudo systemctl restart xrdp
```

## Troubleshooting

### Module Won't Load

**Problem:** `pw-cli load-module` fails

**Solutions:**

1. **Ensure you include required arguments:**
   ```bash
   # CORRECT - with arguments
   pw-cli load-module libpipewire-module-xrdp '{ sink.stream.props={} source.stream.props={} }'

   # WRONG - without arguments (will fail with "Invalid argument")
   pw-cli load-module libpipewire-module-xrdp
   ```

2. Check module path:
   ```bash
   # Find where modules are installed
   find /usr -name "libpipewire-*.so" 2>/dev/null | head -5

   # Use absolute path with arguments
   pw-cli load-module /full/path/to/libpipewire-module-xrdp.so '{ sink.stream.props={} source.stream.props={} }'
   ```

3. Check dependencies:
   ```bash
   ldd build/src/.libs/libpipewire-module-xrdp.so
   ```

4. Check PipeWire logs:
   ```bash
   journalctl --user -u pipewire -f
   ```

### FIFOs Not Created

**Problem:** No FIFO files in `/run/user/$(id -u)/`

**Solutions:**

1. Verify module loaded:
   ```bash
   pw-cli ls Module | grep xrdp
   ```

2. Check permissions:
   ```bash
   ls -ld /run/user/$(id -u)
   ```

3. Manual FIFO creation test:
   ```bash
   mkfifo /tmp/test.fifo
   ls -l /tmp/test.fifo  # Should show 'p' type
   ```

### No Audio Output

**Problem:** Audio plays but nothing in FIFO

**Solutions:**

1. Check if sink is default:
   ```bash
   pactl info | grep "Default Sink"

   # Set as default
   pactl set-default-sink xrdp-sink
   ```

2. Monitor FIFO:
   ```bash
   # This should block, waiting for writer
   cat /run/user/$(id -u)/xrdp_spk.pcm
   ```

3. Test with direct write:
   ```bash
   # Generate test audio directly to FIFO
   ffmpeg -f lavfi -i "sine=frequency=440:duration=5" \
          -f s16le -ar 48000 -ac 2 \
          /run/user/$(id -u)/xrdp_spk.pcm
   ```

### FFmpeg Manager Not Working

**Problem:** FFmpeg processes crash or don't start

**Solutions:**

1. Check logs:
   ```bash
   tail -100 /run/user/$(id -u)/xrdp_ffmpeg_*.log
   ```

2. Test FFmpeg manually:
   ```bash
   # Test speaker encoder
   ffmpeg -f s16le -ar 48000 -ac 2 \
          -i /run/user/$(id -u)/xrdp_spk.pcm \
          -c:a libopus -b:a 64k \
          test_output.opus
   ```

3. Verify format file exists:
   ```bash
   cat /run/user/$(id -u)/xrdp_audio_format.txt
   ```

### Permission Denied Errors

**Problem:** Cannot access FIFOs

**Solutions:**

1. Check ownership:
   ```bash
   ls -l /run/user/$(id -u)/xrdp_*.pcm
   # Should be owned by your user
   ```

2. Fix permissions:
   ```bash
   chmod 644 /run/user/$(id -u)/xrdp_*.pcm
   ```

3. Check SELinux (RHEL/Fedora):
   ```bash
   getenforce
   # If Enforcing, try:
   sudo setenforce 0  # Temporary
   # Then test again
   ```

### High CPU Usage

**Problem:** FFmpeg or module using too much CPU

**Solutions:**

1. Reduce encoding quality:
   Edit `ffmpeg_manager.sh`, change:
   ```bash
   -c:a libopus -b:a 64k  # to
   -c:a libopus -b:a 32k
   ```

2. Check for looping errors:
   ```bash
   ./scripts/ffmpeg_manager.sh status
   # Look for rapid restarts
   ```

3. Monitor with htop:
   ```bash
   htop -p $(cat /run/user/$(id -u)/xrdp_ffmpeg_*.pid)
   ```
